# Reconnaissance and Enumeration

## Overview
This section documents exercises for discovering and mapping a web application's attack surface in authorized lab environments.

## Topics
- Technology identification
- Subdomains
- Directories and endpoints
- Parameters and login pages
- API endpoints and hidden functionality
- Basic information gathering

## Evidence
Reports, screenshots, commands, and observations will be included for completed exercises.

## Key Learning
Understand how reconnaissance helps identify an application's exposed attack surface.
