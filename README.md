# WAPT Phase 1 — Web Application Penetration Testing

**Program:** WAPT Internship  
**Organization:** IqraSec Academy  
**Focus:** Web Application Security and Ethical Hacking

## About This Repository

This repository documents my learning and practical work during Phase 1 of the Web Application Penetration Testing (WAPT) internship.

It covers web fundamentals, reconnaissance and enumeration, Burp Suite, and common web application vulnerabilities. The repository will include reports, screenshots, testing observations, and key learnings from completed exercises.

## Learning Modules

1. **Web Fundamentals** — HTTP/HTTPS, requests and responses, headers, cookies, sessions, authentication, status codes, and APIs.
2. **Reconnaissance & Enumeration** — Technology identification, subdomains, directories, endpoints, parameters, and information gathering.
3. **Burp Suite** — Proxy, HTTP History, Repeater, Intruder, and request/response analysis.
4. **Common Web Vulnerabilities** — SQL Injection, Cross-Site Scripting (XSS), authentication vulnerabilities, IDOR, broken access control, CSRF, path traversal, and file-upload vulnerabilities.

## Repository Structure

- `01-Web-Fundamentals/` — Notes, reports, and practical evidence.
- `02-Recon-Enumeration/` — Reconnaissance exercises and findings.
- `03-Burp-Suite/` — Burp Suite exercises and traffic analysis.
- `04-Web-Vulnerabilities/` — Vulnerability testing reports and evidence.
- `Task-Guides/` — Internship task instructions and reference documents.

## Report Documentation

Reports will document the objective, concepts, testing approach, tools used, evidence, results, impact, remediation, and key learnings, as applicable to each task.
