# Burp Suite

## Overview
This section covers using Burp Suite to intercept, inspect, and modify web traffic in authorized testing environments.

## Topics
- Proxy
- HTTP History
- Repeater
- Intruder
- Decoder
- Request and response analysis
- Modifying requests and testing application behavior

## Evidence
Practical reports and screenshots will be added for completed exercises. Sensitive cookies, credentials, and tokens must be redacted.
