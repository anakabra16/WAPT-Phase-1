# Common Web Vulnerabilities

## Overview
This section documents practical learning about common web application vulnerabilities through authorized labs.

## Topics
- SQL Injection
- Cross-Site Scripting (XSS)
- Authentication vulnerabilities
- IDOR and broken access control
- Cross-Site Request Forgery (CSRF)
- Path traversal
- File-upload vulnerabilities
- Command injection

## Report Contents
Where applicable, reports will cover the lab name, objective, vulnerability concept, testing approach, evidence, impact, remediation, and key learnings.

## Evidence
Only completed exercises and verified observations will be documented.
